# Full Cybersecurity Course

The course is self-paced. Complete lessons in standard order, prioritize a module, or review individual lessons in any order. Each lesson contains reasoning, a worked example, a practical task, a knowledge check, and a completion checklist.

| Module | Lessons | Topics |
| --- | ---: | --- |
| Computer Fundamentals | 4 | Hardware, processes, storage, and lab isolation |
| Networking Fundamentals | 4 | Layers, IPv4 and IPv6, common services, and packet interpretation |
| Linux Fundamentals | 4 | Terminal navigation, permissions, listeners, and logs |
| Windows and Active Directory | 4 | Events, PowerShell inventory, roles, and policy |
| Cybersecurity Fundamentals | 4 | Risk, cryptography, access control, and vulnerability management |
| SOC and Blue Team | 4 | Evidence triage, Wazuh, detections, and response |
| Penetration Testing and Red Team | 4 | Scope, archived Nmap results, Burp evidence review, and reporting |
| Python and Security Automation | 4 | Functions, JSON, API design, and defensive log aggregation |
| Advanced Cybersecurity | 4 | Cloud identity, containers, architecture, and intelligence |
| Practical Cybersecurity Projects | 5 | Telemetry, investigation, detection, assessment reporting, and automation |

Each module closes with a practice assessment. The Crash Course also includes four optional checkpoints alongside the original missions. Keep personal and production data out of practice evidence. The examples use synthetic records or read-only checks on systems you control.

## Learning materials in 2.1

The 41 lessons stay self-paced and now include five four-option questions each. The preparation sections, practice fixtures, and examples are available offline. Open a module in the roadmap to prioritize it for Continue Learning.

The Crash Course uses the original 120 SOC and 120 Pentesting mission IDs. Each mission presents a topic primer, an evidence-specific example, setup and prerequisite material, practice and verification, five checks, and a completion message. Lessons share foundation primers and related tool guides. Additional questions use the authored evidence and goals, with structured choices generated by the catalog compiler. The assessment curriculum emphasizes lab scoping, archived observations, defensive verification, and reporting.
