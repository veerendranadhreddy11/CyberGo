# CyberNex v2.1.0

Open SOC or Pentesting directly from Home. Continue through each sequence at your own pace. The selected start date and actual completion timestamps are used for calendar reporting. Back follows visited pages and deeper routes such as practice and evidence.

All 240 existing mission IDs, checklists, and records are retained. Missions now have study primers, contextual examples, setup guides, five knowledge checks, teaching diagrams, and completion feedback. Full Course lessons retain their self-paced sequence and provide five checks each. Learning progress reports are generated locally as PDFs.

The existing app data directory and SQLite schema stay compatible with earlier CyberNex data. Export a backup before upgrading. Windows packages are unsigned. Mac packages use ad hoc signing and lack notarization.
