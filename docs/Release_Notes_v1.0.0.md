# CyberGo v1.0.0

CyberGo packages both original 120-day learning tracks with a local dashboard, configurable start date, SQLite progress, evidence storage, and a portable backup format. It opens directly without an account.

The release workflow builds Windows x64, macOS Apple Silicon, and macOS Intel packages. The macOS builds use ad hoc signing and are not Apple-notarized. Windows builds have no publisher signature. Device security policy may restrict their installation or launch.

Verify downloads with SHA256SUMS.txt. Export progress before changing computers or removing an installation.
