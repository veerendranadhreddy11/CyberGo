# CyberNex v2.2.0

This is the first installer release with the self-paced SOC Analyst and Red Team & Penetration Testing paths. Each begins with **Module 1 — Computer and Cybersecurity Foundations** and **Lesson 1 — What Is a Computer?**. Neither opening lesson requires additional software. Continue Learning follows prerequisites and saves progress locally.

This release includes six lessons per path. The broader beginner sequence and the later labs, advanced modules, and capstones are still being developed. Earlier progress, notes, quiz attempts, and evidence remain accessible from the learning archive. The SQLite location and application identifier are unchanged.

Windows packages are unsigned. The Mac packages use ad hoc signatures and lack notarization.
